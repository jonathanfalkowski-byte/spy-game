REVELATIONS CHAPTER WRITING SPEC
Write a browser visual-novel chapter as a single JS file.

FORMAT (exact):
(function () {
  window.STORY = window.STORY || {};
  Object.assign(window.STORY, {
    cXX_start: { chapter: "cXX", location: "...", speaker: "", pages: ["..."], next: "cXX_..." },
  });
})();

NODE FIELDS:
- chapter: "c02" etc
- location, speaker (empty string if narration)
- pages: array of 1-4 strings. EACH page 140-280 words. This is how we hit novel length.
- or text: one string
- next: node id
- choices: [{ text, to, effects, require }]
- effects: { cover, integrity, corruption, heat, body } as deltas, gender, flags: {}
- journal: short dossier line
- require on choices: { flag, notFlag, anyFlag:[], startGender, gender, min:{}, max:{} }

TOKENS in prose: {{name}} only. Narration is second person (you / your / yourself). Never interpolate player pronouns with {{he}}/{{him}}/{{she}}/{{her}} — those become she/her on a female start and collide with other women in the room. NPCs talking about the player in the room should use you, {{name}}, or they.

CAST (adults 21+ only): Kane (m), Handler Voss (f — extraction, not the corrupter), Julian Crowe (m), Dr Soren Vale (m), Senator Ives (m), Mia Renn (f — civilian), Marek Pell (m), Subject Zero (f — finished conversion), Captain Radek (m), Nurse Lyle (m), Ellis (m — honey instructor).
Men run Helix and Revelations. They convert and corrupt women (the player if she is female or converted; Subject Zero as the warning). Do not make Crowe, Pell, Vale, Ellis, Lyle, or Kane women. Voss and Mia stay women.

WORLD: The Stack (city). Revelations (private intel). Helix Dynamics / Project CHRYSALIS.

TONE: Spy fiction, second person, specific rooms and bodies. Prefer plain sentences over metaphors and riddles. Do not write "X is a small country," "the cursor is a knife," "hunger is a hallway," or other lines the player has to decode. If a Sunday soup date is at risk, say that. Sex is explicit when the plot earns it, and it should get hotter and raunchier as corruption, heat, and depravity rise. Difficult choices. Consequences stick via flags.

LENGTH:
- Keep the same nodes and roughly the same page count. Pages can be shorter if they are clearer (about 80–200 words). Do not pad with metaphors.
- Specific sensory detail: rain, clinics, trams, offices, bodies — named, not symbolic.

FLAGS YOU MAY SET (only these names):
combat ghost honey prep slept_crowe transitioned half depraved forced_mod sold_voss honest lied_voss double owned ives mia_protected mia_hinted mia_compromised mia_alive shutdown beaten initiated stalled_body agreed_all new_name clinic asked_mia startMale startFemale allow_homo hetero_only bound written pet exhibited creampied ganged masochist bimbo

Every chapter file MUST define cXX_start.
Every chapter except c22 MUST end a spine node with next: "cYY_start" of the following chapter.
c22 endings: c22_identity, c22_double, c22_owned, c22_converted, c22_dead — long epilogues, no next.

Do not write markdown. Do not write a README. JS file only.
