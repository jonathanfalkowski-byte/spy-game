## Visual beat map

Use one row per distinct meaningful trigger. Hold rows can cover many dialogue lines; do not give each speaker or menu a new asset. Use the full stable identifier, for example `c05.s06.shot01`. Give incompatible branch compositions distinct IDs, preserve existing IDs through revision, and never reuse a retired ID.

| SHOT / HOLD | TRIGGER and exact prose anchor | CHARACTERS and positions | LOCATION and time | REQUIRED STATE and conflicting states | DESCRIPTION / continuity | SPEC / ASSET / REVIEW STATUS |
|---|---|---|---|---|---|---|
| Opening shot ID | Actual scene entry | Physical participants; remote medium separately | Locked layout and established lighting | Completed arrival and branch eligibility | Current arrangement, clothes, props | Reference, asset revision or production gap |
| HOLD opening shot ID | Dialogue-only span / choice menu | Same arrangement | Same setting | No meaningful change has occurred | Keep current composition | No additional asset |
| Next stable shot ID | Completed meaningful action | Actual resulting positions | Actual new location or retained layout | Prerequisite action complete; exclude contrary branch | Result of action, never its unchosen future | Pending until reviewed and approved |

An unshown journey does not authorize invented elevator/car/lobby scenes. If prose establishes each location, map each. A micro-gesture stays within a hold unless it carries a significant narrative action. Material time changes use lighting variants of the same canonical space.

- Description of the current resulting beat:
- Prior valid shot and continuity carried across the cut:
- Following dialogue hold; next authored cut trigger:
- Specification link / candidate asset and revision / review decision / human approval evidence / production binding:

Art depicts state; it cannot establish biography, identity acceptance, attraction, consent, knowledge or custody. In particular, do not reveal an unknown caller's face, imply physical presence during a voice call, or show contact continuing after withdrawal.

## Review findings and closure

Answer all eight questions in the linked checklist, then record:

| FLAG | SCENE / BEAT / SHOT | PROSE ANCHOR / ACTUAL STATE | MISMATCH | REQUIRED CORRECTION | STATUS / EVIDENCE |
|---|---|---|---|---|---|
| Exact checklist flag | Stable references | Quoted short anchor and branch | Concrete discrepancy | Specification, asset or separately authorized prose correction | Open / resolved / deferred; reviewer and evidence |

List missing production assets separately. Record what has actually been checked: authoring map, candidate image, owner approval, runtime binding, or branch playback. Do not call the last four complete merely because the map exists. PASS does not promote anything.
