# EVE GLOBAL CINEMATIC ART RULES

These rules apply to ALL current and future EVE chapters.

They govern both:

1. how narrative scenes are written
2. when visual assets are required

The goal is a cinematic visual-novel presentation where the artwork follows physical action without changing unnecessarily during ordinary conversation.

# CORE RULE

HOLD ON DIALOGUE.
CUT ON ACTION.

If characters remain in the same physical arrangement and are simply speaking, KEEP THE CURRENT ARTWORK.

Do NOT generate or switch images merely because:

- a new dialogue line begins
- the speaker changes
- the emotional tone changes
- someone asks a question
- someone pauses
- someone thinks
- a choice menu appears

The artwork remains stable until something visually meaningful changes.

# RULE 1 — DIALOGUE HOLDS THE SHOT

Example:

Evelynn and Julian are seated across from one another at a café.

Julian speaks.
Evelynn answers.
Julian asks another question.
Evelynn challenges him.
Julian answers.

This remains ONE image.

Do not create:
- Julian talking image
- Evelynn talking image
- Julian reaction image
- Evelynn reaction image

unless a physical action changes the visual composition.

The scene should feel like a held cinematic camera shot.

# RULE 2 — CHARACTER ENTRY REQUIRES A NEW SHOT

When a new character physically enters the scene:

NEW ART REQUIRED.

Examples:

- Maya enters the apartment
- Marcus joins Evelynn and Julian
- a waiter approaches with something narratively important
- Sloane enters the room
- security arrives
- another executive joins the table

The new image must show the UPDATED spatial composition.

Do not keep showing two people if the prose now contains three.

# RULE 3 — NEW COMMUNICATION PARTICIPANT

When a new significant character enters an active communication:

CREATE OR SWITCH TO AN APPROPRIATE VISUAL STATE.

Examples:

- Evelynn answers Maya's video call
- Rook appears through a secure video channel
- Sloane joins an existing conference call
- Julian joins a remote meeting

For voice-only communication, do NOT falsely depict the remote character as physically present.

Use an appropriate visual convention such as:

- Evelynn holding the phone
- split communication composition
- device/interface portrait
- caller portrait inset
- established communications UI

The artwork must communicate the actual medium.

Phone ≠ person physically in room.

# RULE 4 — PHYSICAL MOVEMENT REQUIRES A NEW SHOT

If the prose describes a visible physical movement that changes the scene composition, CREATE A NEW ART SHOT.

Examples:

- Evelynn stands
- Evelynn crosses the room
- Julian gets up from the table
- someone approaches another character
- someone moves away
- someone sits beside another character
- someone leaves
- someone enters a car
- someone exits a car
- someone walks into another room
- someone goes onto a balcony
- someone approaches a window
- someone kneels, lies down or changes significant posture
- two characters move from opposite sides of the room to close proximity

The next artwork should show the RESULT of that movement.

The image should follow the prose chronologically.

Example:

PROSE:
“Julian rises and walks toward the terrace doors.”

ART:
New image with Julian now near the terrace doors.

Do not continue displaying him seated.

# RULE 5 — IMPORTANT OBJECT INTERACTION REQUIRES A NEW SHOT

If an object interaction is visually important to the story, create a corresponding shot.

Examples:

- Evelynn opens a package
- places a photograph on the desk
- picks up a secure phone
- receives jewelry
- opens a confidential file
- hangs a dress
- places Adrian's jacket into storage
- signs a document
- takes Julian's offered key/card/device
- destroys or conceals evidence

The visual must accurately show:

- which object
- who possesses it
- where it is
- what happened to it

This is especially important for evidence and symbolic objects.

# RULE 6 — LOCATION CHANGE ALWAYS REQUIRES NEW ART

Any physical location change requires a new visual.

Examples:

apartment
→ elevator

elevator
→ street

street
→ car

car
→ Helix

Helix lobby
→ Julian's office

office
→ restaurant

restaurant
→ hotel lobby

Do not reuse the previous location because dialogue continues across the transition.

# RULE 7 — TIME CHANGE MAY REQUIRE NEW ART

When time changes enough to materially change lighting or environment, use the appropriate visual variant.

Examples:

day
→ evening

evening
→ night

night
→ following morning

Do not redraw the environment from scratch.

Use the established canonical environment and change:

- lighting
- weather if established
- temporary props
- character wardrobe if actually changed

Maintain geography.

# RULE 8 — MOVEMENT IN PROSE CREATES AN ART COMMITMENT

CRITICAL WRITING RULE:

Do not casually write movement that we are unwilling to illustrate.

Every meaningful physical action in player-facing prose creates a visual requirement.

Before writing:

“She crosses the room and stands beside Julian.”

the author should understand that a new image will be needed showing that new composition.

Therefore writers should avoid meaningless blocking such as:

- stands for no reason
- walks to the window repeatedly
- crosses the room simply to break dialogue
- constantly picks things up
- unnecessary pacing
- repeated sitting/standing

Movement should have narrative purpose.

This will reduce art count while making every visual change meaningful.

# RULE 9 — MICRO-MOVEMENT DOES NOT AUTOMATICALLY REQUIRE A NEW SHOT

Do NOT create a new asset for every tiny gesture during dialogue.

Normally the existing image can carry:

- blinking
- breathing
- brief smile
- eyebrow movement
- small head turn
- looking down
- subtle hand movement
- sip of a drink
- minor facial reaction

UNLESS the prose makes that action a major visual beat.

Example:

“Julian smiles slightly.”

Same art.

But:

“Julian removes his wedding ring and places it between them.”

NEW ART.

The distinction is:

MICRO EXPRESSION
versus
NARRATIVE ACTION.

# RULE 10 — SPATIAL RELATIONSHIP CHANGES REQUIRE NEW ART

If the relationship between bodies changes visually, create a new shot.

Examples:

across table
→ sitting beside each other

standing apart
→ close physical proximity

public room
→ private alcove

handshake distance
→ embrace

conversation
→ kiss

standing
→ seated together

These changes matter particularly for:

- attraction
- intimidation
- intimacy
- control
- vulnerability
- negotiation

The image must not imply more physical closeness than the player has authorized.

# RULE 11 — INTIMATE SCENES FOLLOW THE SAME RULES

Adult/intimate scene presentation uses the same visual grammar.

Do not jump visually ahead of canonical consent or action.

Examples:

Conversation on couch:
HOLD.

Evelynn deliberately moves beside Julian:
NEW SHOT.

They kiss after explicit canonical authorization:
NEW SHOT.

They stop or separate:
NEW SHOT.

Withdrawal:
NEW SHOT showing the changed distance.

The artwork must never imply:

- sex before authorized outcome
- nudity before canonical state
- intimacy after withdrawal
- coercion where canonical encounter is voluntary
- voluntary desire where only compliance is established

AdultSceneSpec remains authoritative.

Art follows canonical state.
Art never creates canonical state.

# RULE 12 — CHOICE MENUS DO NOT CHANGE ART BY THEMSELVES

A choice appearing is not an action.

Keep the current shot while the player decides.

Example:

Current image:
Evelynn and Julian sitting at dinner.

Choices:

- Stay professional
- Flirt
- Ask about Helix
- End the evening

Do not switch art yet.

After the player selects:

“End the evening”

then the prose says:

“Evelynn stands and reaches for her coat.”

NOW create/switch to the movement shot.

This ensures the artwork never predicts the player's choice.

# RULE 13 — ART MUST FOLLOW, NEVER SPOIL

Never show something before the prose/player action establishes it.

Do not show:

- a character before they enter
- a gift before it is revealed
- a weapon before discovered
- Julian physically close before the player allows it
- published imagery before publication happens
- evidence in Evelynn's possession before she acquires it
- another character reading something before delivery

Art must represent the CURRENT canonical beat.

Not the next beat.

# RULE 14 — BRANCH-SAFE VISUALS

Each visual asset must declare the state required for it to be valid.

Where relevant include:

- scene ID
- beat ID
- location
- time
- present characters
- wardrobe
- presentation
- physical positions
- evidence/object possession
- relationship/intimacy boundary
- prior required action
- prohibited conflicting state

Do not show a branch-specific image on another route merely because the location matches.

# RULE 15 — SHOT IDS

Introduce stable shot identifiers where useful.

Suggested format:

c05.s06.shot01
c05.s06.shot02
c05.s06.shot03

Each movement/action beat maps to the next visual shot.

Example:

c05.s06.shot01
Evelynn at reception with two guests.

Dialogue continues.
No art change.

PROSE:
“Julian enters from the gallery.”

c05.s06.shot02
Evelynn, guests and Julian.

Dialogue continues.
No art change.

PROSE:
“Evelynn leaves the group and joins Julian by the terrace.”

c05.s06.shot03
Evelynn and Julian at terrace.

This makes prose/art synchronization deterministic.

# RULE 16 — SCENE VISUAL PLAN

For every new major scene, create a simple visual beat map.

Format:

SHOT | TRIGGER | CHARACTERS | LOCATION | REQUIRED STATE | DESCRIPTION

Example:

SHOT 01
Trigger: scene entry
Characters: Evelynn, Julian
Location: café table
Description: seated opposite each other

SHOT 02
Trigger: Julian stands and moves to terrace
Characters: Evelynn seated, Julian standing by terrace
Description: new spatial composition

SHOT 03
Trigger: Evelynn joins Julian
Characters: Evelynn and Julian standing at terrace
Description: closer but still non-intimate

Do not generate separate art for dialogue between those triggers.

# RULE 17 — ART COUNT CONTROL

This rule should create a cinematic game, not thousands of redundant images.

Control art count by controlling unnecessary prose movement.

Before adding a movement beat ask:

DOES THIS ACTION MATTER?

If no:
keep the characters where they are.

If yes:
write it clearly and create the corresponding shot requirement.

Preferred pattern:

ENTER
→ HOLD
→ MEANINGFUL MOVEMENT
→ HOLD
→ NEW CHARACTER / LOCATION
→ NEW SHOT
→ HOLD

Not:

line
→ image
→ line
→ image
→ line
→ image

# RULE 18 — CONTINUITY

Every movement shot must preserve:

- character face
- hair
- age
- body proportions
- wardrobe
- accessories
- environment geography
- lighting continuity
- object custody
- weather
- time
- injuries/marks if any

A character cannot spontaneously change clothes because the camera moved.

A glass cannot jump hands.

A phone cannot disappear.

Furniture cannot rearrange.

Julian cannot change age/appearance.

Evelynn must remain consistent with the approved canonical reference.

# RULE 19 — ENVIRONMENT CANON

Recurring locations must use their locked canonical layout.

Especially:

ADRIAN / EVELYNN APARTMENT

All new apartment shots must use the approved apartment geography.

Movement means moving characters inside the established room.

It does NOT authorize redesigning the apartment.

Same applies to any future locked recurring environment.

# RULE 20 — ART PRODUCTION STATUS

Generated assets follow:

SPEC
→ STAGING
→ REVIEW
→ PASS / REVISE / REJECT
→ HUMAN APPROVAL
→ PRODUCTION

PASS does not automatically mean canonical.

No generated image enters production solely because a scene references it.

# RULE 21 — PROSE/ART VALIDATION

Add an authoring review that asks:

For each scene:

1. Where does the shot begin?
2. Which lines are dialogue-only?
3. Where does physical movement occur?
4. Does every meaningful movement have a corresponding visual requirement?
5. Does any visual change happen without an authored trigger?
6. Does any image show a future action?
7. Does character/object continuity survive the cut?
8. Could unnecessary movement be removed to reduce redundant art?

Flag:

MOVEMENT_WITHOUT_SHOT
SHOT_WITHOUT_TRIGGER
FUTURE_STATE_VISUAL
CHARACTER_CONTINUITY_MISMATCH
OBJECT_CUSTODY_MISMATCH
LOCATION_CONTINUITY_MISMATCH
WARDROBE_MISMATCH
INTIMACY_STATE_MISMATCH

# GLOBAL VISUAL PRINCIPLE

Dialogue is performed within a shot.

Action changes the shot.

The camera should move because the story moved.
