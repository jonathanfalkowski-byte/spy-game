# KNOWLEDGE reviewer v1

For each important NPC statement ask how that person could know it. Use only npc.known, npc.beliefs, observed actions, shared events, sourced disclosures, and represented public knowledge. Inspect the complete action transition before attributing a line: the player-selected utterance or thought, every emitted history record, the NPC response, next-scene narration, and resulting knowledge state all belong to the evidence. Flag unsourced knowledge with current and state evidence. Do not assume NPC omniscience and do not invent an unseen source.
