# Alternate endings — open after your first walkthrough

These are generated review runs, not copies of your personal save. All 13 backups pass the same schema validation and deterministic replay used by the game. `index.json` records their scene, action count, and SHA-256. Regenerate with `node scripts/prepare-review.mjs` after changing content.

First finish one uninterrupted route. Download your own backup before trying these files. In the game choose **Restore save backup**, select a JSON file, inspect the validated location, download the current run if needed, and confirm replacement. The file remains untouched. Restore your personal backup the same way afterward.

| File prefix | Review purpose |
| --- | --- |
| 01 | Cautious withdrawal before biometric authorization |
| 02 | Refusal, delivered contact, and departure |
| 03–05 | Clinic stopping before treatment, after voice change, and after facial change |
| 06 | Supported identification: timely audio, photograph, or token |
| 07 | Withheld identification: fragmentary audio, contact photograph, or failed theft |
| 08 | Correct guess with unsupported reasoning |
| 09 | Unsupported wrong accusation |

The package supplies outcomes for review, not a recommendation about which choices to make. No route resolves the larger Evelyn mystery.
